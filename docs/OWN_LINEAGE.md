# Own Lineage

One Mind and Agent Colony evolve together through receipts.
They do not merge.

- Every receipt carries `source` and `lineage`.
- Import marks `_imported` but does not change `lineage`.
- A foreign fingerprint may alter a local prior.
- It never copies the remote keep/reject.
- Adoption feedback stays in the receiving system.
- Colony keep path remains Oracle + twin + human authorize.
- One Mind keep path remains its own (relaxed) rules.

Co-evolution without identity loss.
